# 五分钟讲解稿（只讲作品，不虚构履历）

**0:00–0:45 业务问题。** 户用光伏站点容量、朝向、天气不同，不能直接按总电量低就判断低效。本作品用合成设备时序展示“观测是否可信、同工况是否偏低、证据如何交给人工核验”。若有工业设备时序经验，可以讨论时间对齐、质量位、状态机和维护闭环的迁移；这里不声称用户已有任何具体履历。

**0:45–1:30 链路。** 演示Shell按阶段处理分区，Raw SHA不变；ODS原文定位，DWD区分坏数值与可信故障观测，DWS计算kWh/PR/覆盖，ADS组合候选风险。打开一条quarantine，沿源行定位，解释对账守恒和为什么电压异常不直接删掉。

**1:30–2:15 低效。** 展示同区域匹配同行的容量归一偏差；不足5个明确不可判定。再解释自身过去健康PR与物理气象基准。阴雨会共同下降，同行可能漏共模异常，物理模型又受辐照传感器偏差影响，所以输出候选原因和置信状态，不能声称唯一诊断。

**2:15–3:00 验证。** 预测5分钟功率，区间积分为日能量；gamma是每°C，不是百分数直接混用。训练1–8月，验证9–10月，测试11–12月；不给模型看simulation_truth，不用未来工单筛数据。展示三模型MAE、RMSE、容量归一误差及滚动回测。不将同气象基准叫日前预测，不声称LSTM一定好。

**3:00–3:45 排查误报。** 打开FP/FN例子：短事件受30分钟门槛漏检，传感器偏差可能触发物理残差；容量档案错误也会改变PR。事件一对一匹配与点级指标不同，无正例指标N/A。覆盖不足时疑似损失不代表已确认故障损失。

**3:45–4:30 Shell恢复。** 展示故障注入返回1，无watermark和完成receipt；临时源错误75重试；重跑输出verified_content；锁冲突73。不只说“有日志”，展示step/date/attempt/duration/count/exit_code如何定位失败。说明SIGKILL必须手工核验残留锁。

**4:30–5:00 闭环与边界。** 看板筛选与证据钻取，工单待核验→派单→处理中→关闭→复核全部本地模拟；疑似损失不是实际挽回收益。坦诚说明未实现、未验证项及一年季节周期对衰减估计的限制，用验收文件逐项回答。
